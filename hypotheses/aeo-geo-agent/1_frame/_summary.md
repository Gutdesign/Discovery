# Итог этапа: рамка

> 2026-10-23. Все файлы 00–04 одобрены основателем.

## Гипотеза в одном абзаце

Свой сервис мониторинга (вопросы проектировщиков от лица персон → ChatGPT, Claude, Gemini, Яндекс через API → доля ответов с упоминанием) даст основателю повторяемые метрики видимости СводПро (svodpro.ru) в ответах ИИ. По ним он выберет, какой материал, в каком формате и где публиковать, и увидит, сдвинула ли публикация видимость. Продажа сервиса внешним — позже, сейчас не проверяется. Подтверждено, если выполнены два из трёх: метрики стабильны при повторе; по ним принято решение; после публикации — значимый сдвиг.

## Что изменилось по пути

- Из «кейса GoPractice» — во внутренний сервис для СводПро (серия GoPractice — образец устройства).
- Сбор через браузер заменён на API для всех четырёх моделей: для значимости нужны сотни ответов. При нулевой базе хватит ~50 ответов на модель за замер (5 упоминаний после — уже значимо).
- Метрика сайта отклонена как проверка A1: при нулевой видимости заходов нет по определению.

## Самое важное допущение

**A1:** проектировщики выбирают инструменты по ответам ИИ. Проверка первым замером: называют ли модели вообще сервисы (Техэксперт, МегаНорм, Кодекс, NormaCS — ожидание основателя) на вопросы о нормативах и проверке документации.

## Что осталось непроверенным

- S1: совпадает ли ответ API с интерфейсом, особенно Yandex GenSearch и «Поиск с Алисой».
- Довод скептика: при слабом SEO первая мера — обычное SEO, а не мониторинг ИИ.
- Принятый риск: «два из трёх» позволяет засчитать успех без доказанного сдвига.
- Обзор готовых сервисов сделан до записи ожиданий — ожидания о них не чистые.
